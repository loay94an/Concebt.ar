# مفاهيم للرسم — النسخة العربية

تطبيق Android مستقل باللغة العربية، يعيد تنفيذ مجموعة أولية من أدوات الرسم بواجهة RTL. هذه نسخة إعادة بناء مستقلة وليست نسخة معدلة من APK الأصلي أو استعادة لمصدر Concepts المغلق.

## ما يعمل في الإصدار 0.4.0

- لوحة رسم بخلفية ورقية وشبكة خفيفة.
- أدوات القلم والرصاص والمُحدِّد والممحاة وتحريك اللوحة، والخط والمستطيل والبيضاوي والقياس.
- تسجيل ضغط القلم وميله واتجاهه، مع تنعيم المسارات وحفظ بيانات القلم في صيغة ملفات v5 متوافقة مع الصيغ السابقة.
- ألوان وسماكة قابلة للتغيير.
- طبقات مستقلة مع الإضافة والاختيار والإظهار والإخفاء والحذف.
- تراجع وإعادة حتى 40 خطوة.
- حفظ تلقائي محلي بصيغة ثنائية، مع استبدال ذري للملف عند دعم نظام الملفات.
- تصدير SVG وPDF مع الصور المضمنة وحدود الرسم والطبقات الظاهرة.
- معرض مستندات متعدد، واستيراد الصور وإدراجها على اللوحة.\n- تكبير وتصغير متعدد اللمس مع تحريك اللوحة بإصبع واحد.\n- واجهة عربية RTL ووضع فاتح/داكن.

- [تعليمات إعداد GitHub Actions](reverse-engineering/GITHUB_ACTIONS_SETUP_AR.md)

- [تقرير REA الأولي الناجح](reverse-engineering/REA_CONCEPTS_ORIGINAL_REPORT_AR.md)

التقرير الآلي لا ينشر الشيفرة المفكوكة أو الأصول أو المكتبات الثنائية. كما أن JADX تحليل ثابت؛ لا يثبت سلوك التطبيق وقت التشغيل. تم تنفيذ REA فعلياً على العينة، وتقرير التحليل المتعمق مستقل عنه.

## غير منفذ بعد

هذه النسخة لا تضم محرك Concepts الأصلي ولا تعيد تنفيذ كل خصائصه. ما زالت بحاجة إلى مزيد من تحسين استجابة القلم، تحريك/تغيير حجم الصور والعناصر، أدوات القياس المتقدمة، PSD/DXF، إدارة الصفحات واللوحات الفنية، وتحسين أداء الرسومات الكبيرة. يلزم اختبار فعلي على هاتف وقلم رقمي قبل اعتبار تجربة الرسم معتمدة.

## البناء محلياً

يتطلب JDK 17 وAndroid SDK 35 وGradle 8.11.1:

```bash
gradle testDebugUnitTest
gradle assembleDebug
```

ملف APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

يُنشر APK الاختبار آلياً كـ Artifact باسم `concepts-arabic-debug-apk` لمدة 30 يوماً.

## الخصوصية

الرسم محفوظ محلياً داخل مساحة التطبيق الخاصة. لا توجد في هذا الإصدار حسابات أو خدمات سحابية أو تحليلات أو صلاحيات شبكة.
