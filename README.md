# مفاهيم للرسم — النسخة العربية

تطبيق Android مستقل باللغة العربية، يعيد تنفيذ مجموعة أولية من أدوات الرسم بواجهة RTL. هذه نسخة إعادة بناء مستقلة وليست نسخة معدلة من APK الأصلي أو استعادة لمصدر Concepts المغلق.

## ما يعمل في الإصدار 0.2.0

- لوحة رسم بخلفية ورقية وشبكة خفيفة.
- أدوات القلم والرصاص والمُحدِّد والممحاة وتحريك اللوحة.
- ألوان وسماكة قابلة للتغيير.
- طبقات مستقلة مع الإضافة والاختيار والإظهار والإخفاء والحذف.
- تراجع وإعادة حتى 40 خطوة.
- حفظ تلقائي محلي بصيغة ثنائية، مع استبدال ذري للملف عند دعم نظام الملفات.
- تصدير SVG بمساحة رسم محسوبة من حدود المحتوى، مع دعم النقطة المفردة والطبقات الظاهرة.
- واجهة عربية RTL ووضع فاتح/داكن.

## التحقق

تشغّل GitHub Actions اختبارات الوحدة ثم تبني APK تصحيحياً. نجاح CI يثبت نجاح التجميع والاختبارات المضمنة، لكنه لا يغني عن اختبار اللمس والأداء ومشاركة الملفات على أجهزة Android فعلية.

## غير منفذ بعد

هذه النسخة لا تضم محرك Concepts الأصلي. لم تُنفذ بعد ميزات مثل ضغط/ميل القلم، تنعيم احترافي، تكبير/تصغير متعدد اللمس، دليل الأشكال والقياس، استيراد الصور، معرض مستندات متعدد، مزامنة سحابية، أو تصدير PDF/PSD/DXF. كما لم يُشغّل REA على APK الأصلي حتى الآن؛ انظر ملف reverse-engineering/REA_PLAN_AR.md.

## البناء محلياً

يتطلب JDK 17 وAndroid SDK 35 وGradle 8.11.1:

```bash
gradle testDebugUnitTest
gradle assembleDebug
```

ملف APK الناتج:
app/build/outputs/apk/debug/app-debug.apk

يُنشر APK الاختبار آلياً كـ Artifact باسم concepts-arabic-debug-apk لمدة 30 يوماً.

## الخصوصية

الرسم محفوظ محلياً داخل مساحة التطبيق الخاصة. لا توجد في هذا الإصدار حسابات أو خدمات سحابية أو تحليلات أو صلاحيات شبكة.
